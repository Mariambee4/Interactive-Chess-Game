## Interactive Chess Game ♟️

## About the Project

This is a small chess project that I made to make learning and playing chess more interactive.

The website has two main parts: a tutorial and a playable chess game. In the tutorial, you can click on different chess pieces to learn how they move and see the possible moves they can make.

After learning the basics, you can go to the play section and actually play chess.

## What You Can Do

- Learn how each chess piece moves
- See the possible moves of a selected piece
- Practice moving pieces on the board
- Play against a friend on the same device
- Play against the computer
- Restart a game and try again
- Use the website on both computers and phones

## How I Made It

I made this project using:

- HTML
- CSS
- JavaScript

I used CSS Grid for the chessboard and JavaScript to handle the chess pieces, moves, buttons, tutorial, and game logic.

## How to Run It

You can run the project by downloading the files and opening the `index.html` file in a web browser.

You can also use the online version through GitHub Pages once it is set up.

## How to Use the Tutorial

When you open the website, choose **Tutorial**.

From there, select a chess piece on the board. The website will explain how that piece moves and show the squares it can move to.

This is meant to help beginners understand chess before starting a full game.

## Playing the Game

When you are ready, choose **Play**.

You can choose to play against a friend on the same device or play against the computer.

For two-player mode, one player uses White and the other uses Black, and they take turns on the same device.

## Project Goal

The main goal of this project is to combine learning and playing chess in one simple website instead of making the user learn everything before they can interact with the board.
